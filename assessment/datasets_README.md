# Datasets for the assessed project

You may use any of the following, or another dataset approved by the instructor:

- A retention-time dataset (your own, or a public deposition via
  ProteomeXchange/PRIDE), for Option A regression.
- A spectral dataset (IR, Raman, NMR, or mass spectra) with class labels, for
  Option B.
- The instructor-provided flawed notebook, for Option C.
- For a self-contained start, the worked solution `project_solution.ipynb`
  generates an illustrative retention dataset in-notebook; replace it with real
  data for your submission.

State the source and licence of your data in section 1 of the notebook.
